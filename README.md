# محاسبة شاورما — أغسطس

لوحة تحكم محاسبية بسيطة لمطعم شاورما بفرعين (الوسيطاء · بيروت).

## المميزات

- صفحة **الكاش اليومي**: تسجيل كاش فرع الوسيطاء وفرع بيروت معاً من 1 إلى 31 أغسطس
- تسجيل المبيعات يومياً من 1 إلى 31 أغسطس 2026
- تسجيل المشتريات والمصروفات يومياً لكل فرع
- ملخص: كاش كل فرع · إجمالي الكاش · صافي الربح
- حفظ تلقائي على المتصفح (localStorage)

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```
