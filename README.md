# محاسبة شاورما — أغسطس

لوحة تحكم محاسبية بسيطة لمطعم شاورما بفرعين (الوسيطاء · بيروت).

## المميزات

- صفحة **الكاش اليومي**: تسجيل الكاش النقدي فقط من 1 إلى 31 أغسطس لكل فرع
- تسجيل المبيعات يومياً من 1 إلى 31 أغسطس 2026
- تسجيل المشتريات والمصروفات يومياً لكل فرع
- ملخص: إجمالي الكاش · المبيعات · المصروفات · صافي الربح
- حفظ تلقائي على المتصفح (localStorage)

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```
