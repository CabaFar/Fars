# محاسبة شاورما — أغسطس

لوحة تحكم محاسبية بسيطة لمطعم شاورما بفرعين (الوسيطاء · بيروت).

## المميزات

- تسجيل المبيعات يومياً من 1 إلى 31 أغسطس 2026
- تسجيل المشتريات والمصروفات يومياً لكل فرع
- ملخص: إجمالي المبيعات · إجمالي المصروفات · صافي الربح
- حفظ تلقائي على المتصفح (localStorage)

## صفحة مستقلة: سجل الكاش اليومي

صفحة منفصلة تماماً عن محاسبة أغسطس:

- المسار: `/cash.html` (محلياً: `http://localhost:5173/cash.html`)
- تسجيل الكاش ومصروفات الكاش يومياً من 1 إلى 31 أغسطس
- فرع الوسيطاء وفرع بيروت معاً
- تخزين خاص بها (لا يشارك بيانات المحاسبة)

## التشغيل

```bash
npm install
npm run dev
```

- المحاسبة: http://localhost:5173/
- سجل الكاش: http://localhost:5173/cash.html

## البناء

```bash
npm run build
npm run preview
```
