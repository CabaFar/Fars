# محاسبة شاورما — أغسطس

لوحة تحكم محاسبية بسيطة لمطعم شاورما بفرعين (الوسيطاء · بيروت).

## المميزات

- صفحة **الكاش اليومي**: تسجيل كاش ومصروفات الكاش لفرع الوسيطاء وفرع بيروت من 1 إلى 31 أغسطس
- تسجيل المبيعات يومياً من 1 إلى 31 أغسطس 2026
- تسجيل المشتريات والمصروفات يومياً لكل فرع
- ملخص: كاش كل فرع · مصروفات الكاش · صافي الكاش
- حفظ تلقائي على المتصفح (localStorage)

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```
