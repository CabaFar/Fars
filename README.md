# محاسبة شاورما — أغسطس

لوحة تحكم محاسبية بسيطة لمطعم شاورما بفرعين (الوسيطاء · بيروت).

## المميزات

- تسجيل المبيعات يومياً من 1 إلى 31 أغسطس 2026
- تسجيل المشتريات والمصروفات يومياً لكل فرع
- ملخص: إجمالي المبيعات · إجمالي المصروفات · صافي الربح
- حفظ تلقائي على المتصفح (localStorage)

## صفحة مستقلة: سجل الكاش اليومي

صفحة منفصلة تماماً عن محاسبة أغسطس:

- المسار: `/cash.html` (محلياً: `http://localhost:5173/cash.html`)
- تسجيل الكاش ومصروفات الكاش يومياً من 1 إلى 31 أغسطس
- فرع الوسيطاء وفرع بيروت معاً
- تخزين خاص بها (لا يشارك بيانات المحاسبة)

## صفحة مستقلة: مخزون المطعم

لوحة حمراء وبيضاء لإدارة المخزون اليومي:

- المسار: `/inventory.html` (محلياً: `http://localhost:5173/inventory.html`)
- تبويب الأسعار: سعر الكيلو أو الكرتون أو الحبة لكل صنف
- صباح: الكمية × سعر الوحدة = الإجمالي
- مساء: الجرد الفعلي (الباقي)
- أول المدة = الموجود أول اليوم، ويُرحَّل من جرد أمس
- المستهلك = أول المدة + المشترى − الجرد
- الخضار تُسجَّل بالريال، والدجاج والبهارات بالكيلو
- جرد يومي للأصناف سريعة الحركة، وجرد أسبوعي للباقي
- تنبيه عند النقص أو خطأ العدّ
- نسخة احتياطية JSON من المتصفح

## التشغيل

```bash
npm install
npm run dev
```

- المحاسبة: http://localhost:5173/
- سجل الكاش: http://localhost:5173/cash.html
- المخزون: http://localhost:5173/inventory.html
